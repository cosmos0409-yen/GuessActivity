# 司法官學院千元小學堂－決賽（闖關猜謎 App）

給主持人與主辦單位看的操作說明。程式開發細節請看 `doc/handover.md`。

## 這是什麼

這是一套現場闖關型猜謎遊戲，設計給司法官學院學員活動使用：參賽者一路答對法律與知識題目往上闖關，答錯就出局，也可以選擇在過關後「帶走目前的獎勵」退出。全程由一位主持人在筆電操作、投影到大螢幕，觀眾可以用手機投票支援。

> **同一個資料夾裡還有「選拔賽」系統（全場搶答）**：活動開始時讓全場 150 人用手機搶答，選出前 3 名上台參加這個決賽。它放在 `live-quiz/` 資料夾，架在 Cloudflare 上，網址是 https://live-quiz.cosmos0409.workers.dev 。使用方式、部署、換題庫請看 `live-quiz/README.md`。
>
> 選拔賽的最終排名畫面按「前往決賽 →」，會開啟本網站並帶上前 3 名的暱稱：大廳會出現這 3 個名字的按鈕，點一下就能帶入挑戰者姓名。
>
> | | 選拔賽（全場搶答） | 決賽（闖關猜謎，本頁） |
> |---|---|---|
> | 誰在玩 | 全場觀眾用手機 | 上台的 3 位參賽者 |
> | 放在哪 | `live-quiz/`，Cloudflare 上的網站 | 專案根目錄，主持人電腦 |
> | 題庫 | 試算表「搶答題」分頁 | 試算表「題目」「題型」分頁 |

## 怎麼啟動

1. 打開終端機，切換到 `C:\猜謎程式`
2. 執行 `npm install`（第一次使用或更新過程式才需要）
3. 執行 `npm run dev`
4. 用瀏覽器開 `http://localhost:5173`，按 `F11` 進入全螢幕

> 關閉遊戲時，在終端機按 `Ctrl+C` 即可停掉伺服器。

## 一場遊戲的流程

1. 大廳畫面輸入參賽者姓名，開始新的一場
2. 每一關：先選題型（**同一場每個題型只能選一次**，選過的題型會變灰並標示「已選過」）→ 顯示題目 → 按空白鍵開始倒數 → 參賽者作答（可使用提示卡）→ 主持人按 Enter 鎖定答案 → 再按 Enter 揭曉結果 → 顯示詳解卡
3. 答對且還沒到最後一關：可以選「帶走目前獎勵」下車，或「繼續挑戰」下一關
4. 答對最後一關：恭喜過關，結算畫面
5. 答錯：直接結算（**沒有保底關**，一律帶走「答錯之前已經通過的關數」對應的獎勵，只是不能再繼續挑戰）
6. 結算畫面（答錯出局／帶走獎勵／全破）可以「開始新的一場」回到大廳，讓主持人輸入下一位參賽者的名字再開始；也可以直接「查看排行榜」

> 如果某一關剩下沒選過的題型全部沒有題目可以抽（10 種題型對 5 關正常不會發生），選題型畫面會出現提示，讓主持人勾選「允許重選已經用過的題型」略過這個限制。

## 3 張提示卡的規則

主持人依參賽者要求，在作答前使用（每張只能用一次）：

| 提示卡 | 快捷鍵 | 效果 |
|---|---|---|
| 刪除一個選項 | `H` | 從三個錯誤選項中刪掉一個（題庫可指定優先刪除哪個，否則隨機） |
| 指定人幫幫忙 | `P` | 場邊或現場找一人小聲提供意見 |
| 全場一起協助 | `V` | 跳出投票視窗：題目、大 QR code 與即時長條圖。可以按「收起」縮成右下角的小視窗（票照收）。收票後，每個選項上會留下全場投票的百分比，直到換下一題 |

**重要：只要用了任何一張提示卡，這一題的 30 秒倒數就永久結束**，之後參賽者不再被計時，由主持人自行掌握節奏、決定何時鎖定答案。

## 快捷鍵表

按 `?` 可以隨時叫出／關閉這份說明。

| 按鍵 | 功能 |
|---|---|
| `Space` | 開始或暫停倒數 |
| `1`–`4` ／ `A`–`D` | 選答案 |
| `Enter` | 鎖定答案／揭曉結果 |
| `→` ／ `PageDown` | 下一步（含收起詳解卡） |
| `H` | 提示卡：刪除一個選項 |
| `P` | 提示卡：指定人幫幫忙 |
| `V` | 提示卡：全場一起協助 |
| `R` | 換題（會先跳出確認） |
| `Ctrl+Z` | 復原上一步 |
| `M` | 靜音／取消靜音 |
| `F` | 切換全螢幕 |
| `?` | 顯示／關閉這份快捷鍵說明 |

（游標在輸入框裡時，所有快捷鍵都會被忽略，不會誤觸。）

## 設定頁每一項的說明

點畫面上的「設定」按鈕開啟，各區塊：

- **基本**：主標題，顯示在大廳畫面上方（例如「司法官學院 闖關大挑戰」）。
- **題庫**：正式的題目與題型網址已經寫在程式裡，換電腦打開就會自動讀取；要改用別的試算表時，才在這裡貼上兩份 CSV 的網址並按「重新讀取題庫」。下方會顯示目前題庫的來源（遠端／本機快取／內建範例）、讀取時間、題數與警告則數。詳見「題庫與投票」。
- **線上投票（全場一起協助）**：正式的 Google 表單與 Apps Script 統計網址已經寫在程式裡，預設就是啟用。線上投票連不上時會自動改成主持人手動輸入百分比。
- **規則**：每題秒數（預設 30 秒）、時間到的處理（直接算答錯，或交由主持人裁量）。沒有保底關設定：答錯一律帶走「答錯之前已經通過的關數」對應的獎勵。
- **音效**：音量調整、靜音開關（跟 `M` 快捷鍵共用同一個狀態）。
- **彩排模式**：開啟後練習用的場次不會標記題目為已使用、也不會寫進排行榜，畫面角落會顯示「彩排中」浮水印。
- **維護**：「重置已使用題目」（讓所有題目重新回到可抽池）、「排行榜與匯出」、「開啟主持人手卡」的進入點。

## 彩排模式、排行榜與匯出、主持人手卡

- **彩排模式**：在設定頁勾選。適合正式活動前對稿、測試流程，不會影響正式資料。
- **排行榜與匯出**：設定頁按「排行榜與匯出」開啟，依通關數排序（同分時用得越少提示卡排越前面），可以按「匯出 CSV」把所有場次紀錄存成檔案，也可以「清除全部紀錄」（無法復原，會先跳確認）。
- **主持人手卡**：設定頁按「開啟主持人手卡」，或直接開 `hostcards.html`。可依題型、難度篩選，也可以勾選「包含待審題目」方便彩排前確認內容；按「列印」（或 `Ctrl+P`）會以一題一張 A4 的版面印出，含答案、詳解與主持人口白。

## 已知限制

`npm run build`（正式打包）在目前電腦的 Node 24 環境下會當掉，屬已知問題。**平常練習與正式活動用 `npm run dev` 開起來玩即可，不受影響**；只有要打包成不需要終端機的版本時才需要處理這個問題。
