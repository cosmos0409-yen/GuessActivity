# 你需要做的事（使用者操作清單）

> 這份是給**你（使用者）**看的清單，只列出必須由你本人或主辦單位操作的事，完成就打勾。
> 程式開發的進度請看 `doc/handover.md`（那份是寫給 Claude 的交接手冊）。
> 最後更新：2026-09-12

---

## 🟢 現在就可以做（在自己的電腦上）

- [ ] **1. 看遊戲畫面，確認美術風格**
  1. 在 `C:\猜謎程式` 資料夾開啟終端機，執行 `npm run dev`
  2. 用瀏覽器開 http://localhost:5173 ，按 F11 全螢幕
  3. 從頭玩一輪；配色、字級、版面、動畫哪裡不喜歡，直接告訴 Claude
  - 想單獨試聽音效：開 http://localhost:5173/soundlab.html
  - 按 `?` 可以叫出快捷鍵說明

- [ ] **2. 刪除除錯留下的暫存檔**
  - 在 `C:\猜謎程式` 根目錄，刪除這 12 個檔案：`b2.log`～`b7.log`、`build_stdout.log`、`build_stderr.log`、`devserver.log`、`err.log`、`out.log`、`vite.config.ts.new`
  - ⚠️ 要刪的是 `vite.config.ts.new`，**不是** `vite.config.ts`
  - Claude 沒有刪除檔案的權限，所以要由你手動刪除

- [ ] **3. 決定要不要把 Node 換成 22 版**
  - 目前電腦上的 Node 24 在「正式打包」（`npm run build`）這一步會當掉；平常用 `npm run dev` 開起來玩不受影響
  - 只有要把遊戲打包成不需要終端機、可以直接帶到現場的版本時才需要處理
  - 換版本需要安裝軟體，同意的話跟 Claude 說，它會帶你操作

## 🟡 活動前要設定（需要你的 Google 帳號）

- [ ] **4. 建立自己的題庫試算表**（如果要用自己的題目取代內建的 52 題範例）
  1. 開一個 Google 試算表，建立兩個分頁：「題目」「題型」
  2. 把 `public/sample-questions.csv`、`public/sample-categories.csv` 分別匯入這兩個分頁當作起點
  3. 欄位說明見 `docs/題庫維護說明.md`（**這份還沒寫**，會在最後一個階段補上）；在那之前，照範例 CSV 的欄位名稱填寫即可
  4. 「檔案 → 共用 → 發布到網路」→ 分別選「題目」「題型」分頁，格式選 **CSV** → 複製兩個網址
  5. 開啟遊戲的設定頁，貼上兩個網址 → 按「重新讀取題庫」
  - ⚠️ 答案也寫在這份試算表裡，**發布出來的網址不要公開**
  - 沒有設定也可以玩，遊戲會使用內建的 52 題範例題庫

- [ ] **5. 設定「全場一起協助」的手機投票**（選做）
  - 照 **`gas/README.md`** 一步一步操作：建立 Google 表單 → 貼上 Apps Script → 部署成網頁應用程式 → 把兩個網址填進設定頁
  - 部署時 Google 會跳出授權畫面，要由你本人按同意
  - 沒有設定也可以玩，會自動改成「主持人手動輸入百分比」
  - 有設定的話，找 5～10 支手機實際掃 QR code 測試一次

## 🔴 需要主辦單位（司法官學院）提供

- [ ] **6. 院徽正式檔案與使用同意**
  - 目前用的是從官網抓的小圖（361×393），投影時會模糊
  - 請承辦單位提供向量檔（AI、SVG 或 PDF）或高解析度 PNG，並確認活動可以使用院徽
  - 拿到後把檔案取名為 `emblem.jpg` 或 `emblem.png`，放進 `public/brand/`，再跟 Claude 說一聲
- [ ] **7. 題庫審閱**
  - 請主辦單位看過 `docs/題庫查核報告.md` 與題目，特別是法律題的正確性與難度
  - 如果想加入學院專屬題型（例如學院大小事），請提供素材
- [ ] **8. 保底關的獎勵內容**
  - 第 3 關是保底關；獎勵名稱（例如「紀念品一份」）決定後告訴 Claude

## 📅 活動當天前 1 天：彩排檢查

- [ ] 用現場那台筆電接投影機，實際跑一場「彩排模式」（在設定頁開啟；不會消耗題目，也不會記進排行榜）
- [ ] 確認投影畫面：字看得清楚、顏色沒有偏掉
- [ ] 確認喇叭音量：音效不會太小聲或爆音
- [ ] 確認簡報筆：按「下一頁」能推進流程
- [ ] 拔掉網路再玩一次：題庫要能正常讀取，投票要自動切到手動輸入
- [ ] 如果有設定手機投票：現場 Wi-Fi 或手機網路能掃 QR code 投票
- [ ] 如果之前做過測試，到設定頁按「重置已使用題目」，並清除排行榜
- [ ] 列印主持人手卡：設定頁有「開啟主持人手卡」，一題一張 A4，裡面有答案、詳解和串場台詞
